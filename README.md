# Problem Solving and Training (PST)

This repository contains problem-solving and coding practice solutions organized by week.

## Structure

- **WEEK 1**: Array operations, comparators, lambda expressions, and sorting algorithms.
- **WEEK 2**: Array manipulations, hash sets, deques, and frequency analysis.
- **WEEK 3**: Date and time operations, priority queues, and sorting algorithms.
- **WEEK 4**: Matrix manipulation, diagonal differences, and matrix rotations.
- **WEEK 5**: Subarrays, Kadane's algorithm variants, and string manipulation.
- **WEEK 6**: Advanced string algorithms, palindromes, and pattern matching.
